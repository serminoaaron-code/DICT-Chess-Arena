Fair Play Rules

  • Leaving the game tab during a live match gives a strike. 3 strikes = automatic forfeit.
  • Missing 3 match prompts removes you from the search queue.
  • Win = 1 point, draw = 0.5 points, loss = 0 points.
  • No email is collected. Sign in with the tournament code (shared) or your personal code from the host, plus your display name and agency. Personal codes give a ✔ verified mark.
  • Only registered players (and the host) can send chat messages. Spectators can read along.
  • The host can remove a player from a server. Removed players cannot rejoin that server until the host allows them back.
